1.Getter adalah method untuk mendapatkan/membaca nilai atribut private.
  Setter adalah method untuk memberikan atau mengubah nilai atribut private.

2.Untuk mendapatkan atau membaca nilai atribut simpanan yang bersifat private.

3. setor ()

4.Konstruktor adalah method khusus yang dijalankan ketika objek dibuat. Nama konstruktor harus sama dengan nama class dan tidak mempunyai tipe return.

5.Nama constructor harus sama dengan nama class.
  Constructor tidak mempunyai tipe data return.
  Constructor tidak boleh menggunakan modifier abstract, static, final, dan synchronized.

6. Java memperbolehkan constructor menggunakan access modifier private, protected, public, maupun default

7. Digunakan ketika objek membutuhkan nilai tertentu ketika pertama kali dibuat.

8. Inisialisasi atribut adalah memberikan nilai awal pada atribut.
   Instansiasi adalah proses membuat objek dari suatu class menggunakan new.

9.Method tidak dibuat sebagai objek secara terpisah. Method dipanggil melalui objek yang telah dibuat.
